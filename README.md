# Telegram Echo Bot

A simple Telegram bot that echoes back any message it receives — useful as a base template for bot development.

## Features
- Echoes text messages
- Handles commands
- Ready-to-extend base structure

## Requirements
```
pip install -r requirements.txt
```

## Configuration
Create a `.env` file next to `echo-bot.py` with your bot token:
```
TOKEN=your_token
```

## Usage
```bash
python echo-bot.py
```
